# Cue · 网页视频学习扩展

这是一个 Chrome / Edge Manifest V3 浏览器扩展。它会在用户主动点击后连接当前网页里的真实 HTML5 视频，使字幕、标注、查词和收藏跟随视频播放时间同步。

## 本机安装

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件夹：

```text
C:\Users\华为\Documents\Codex\2026-10-26\zu\outputs\juxue\extension
```

5. 点击浏览器工具栏的拼图图标，把“Cue”固定到工具栏。
6. 打开一个网页视频并先播放几秒。
7. 点击“Cue”图标。学习面板会直接出现在当前视频页，不经过启动弹窗。

## 分享给别人

浏览器扩展不能像普通网页一样直接上传到 GitHub Pages 使用。GitHub 可以保存源码，别人仍需要安装扩展。

当前 Alpha 版本最简单的分享方式：

1. 把 `cue-extension-0.3.1.zip` 发给对方。
2. 对方解压后打开 `chrome://extensions` 或 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择解压后的文件夹。

要让普通用户像安装商店应用一样使用，应注册 Chrome Web Store 或 Microsoft Edge Add-ons 开发者账号，提交扩展包、隐私说明、功能截图和权限解释。商店审核通过后，对方点击“添加至 Chrome/Edge”即可安装。

## 使用流程

### 已有网站字幕

先在原网站播放器中开启 CC，然后点击“读取网页字幕”。扩展会按照以下顺序自动选择可用的字幕来源：

1. HTML5 播放器的 TextTrack 字幕轨道。
2. 页面中已经渲染出来的网站字幕，例如 YouTube、Video.js、JW Player 等播放器的字幕层。
3. 页面加载过的 `.vtt` / `.srt` 字幕资源地址。

如果网站使用的是私有字幕接口，后续可以针对网站增加适配器。直接拦截所有网页网络请求既不安全，也会受到 Manifest V3 的限制，因此当前版本不使用这种全局抓包方式。

### Bilibili 专用适配

当前版本已接入 Bilibili 视频信息与播放器字幕接口：

1. 从页面获取 BV 号和当前分 P。
2. 通过 `x/web-interface/view` 获取对应 `cid`。
3. 通过 `x/player/v2` 获取平台字幕轨道。
4. 读取 `subtitle_url` 对应的字幕 JSON。
5. 如果有英文和中文字幕轨道，会优先使用英文，并尝试按时间对齐中文翻译。

Bilibili 接口返回 `subtitles: []` 时，说明该视频本身没有 CC 字幕，不是扩展漏读。此时需要 ASR、UP 主添加字幕或手动导入。

如果接口返回的字幕轨道只有中文，Cue 不会再把它误当成英文字幕显示。学习面板需要以英文轨道作为主内容；只有中文字幕时会明确提示改用英文字幕或 ASR。

### 爱奇艺适配

爱奇艺网页播放器不会暴露 `TextTrack`。Cue 通过注入主页面桥接层读取 `QiyiPlayerProphetData`：

1. 读取播放器 `dashData.data.program.stl` 中的字幕轨道。
2. 从 `dstl` 前缀和轨道中的 `pre` / `xml` 字段组合字幕地址。
3. 兼容 JSON 和 XML 字幕格式。
4. 如果爱奇艺没有返回字幕轨道，会明确提示字幕可能是画面内嵌字幕。

当前实测中的爱奇艺网页节目通常没有 `stl` 文本轨道。标题写着“英文字幕”也可能表示字幕已经烧录进视频，这种情况下浏览器扩展无法直接提取文字，需要 OCR 或 ASR。

网站可用跨域限制、私有播放器或 DRM 阻止读取。这时不会伪造字幕，而会提示改用导入方式。

### 导入自己的字幕

点击“导入字幕”，选择 `.srt` 或 `.vtt` 文件。扩展会：

- 解析字幕开始和结束时间。
- 自动识别双语文件里的中文行。
- 把字幕保存在当前网站路径下，下次进入同一页面可重新载入。
- 根据视频真实 `currentTime`、暂停、拖动和倍速同步字幕。

### 学习交互

- 视频画面上会显示 Cue 的字幕层，点击任意英文单词会暂停视频。
- 右侧面板显示中文释义、原句和语境。
- 本地词典可直接提供部分高频表达与单词的中文释义。
- 点击“联网查词”后，扩展才会把当前词语/句子发送到 Free Dictionary API 与 MyMemory，获取音标、英文释义和中文翻译。
- 单词、短语、原句、来源、时间和中文翻译会一起保存到本地词库。
- 支持发音、搜索、掌握状态、删除和 JSON 导出。

## 当前支持边界

这个 Alpha 版本已经接入真实网页视频，但不是“所有网站无条件可用”：

- 支持普通顶层 HTML5 `<video>`。
- 支持可由当前页面权限访问的同源 iframe 播放器；扩展会注入全部 frame，但只让发现视频的 frame 显示面板。
- 支持浏览器可以访问的 TextTrack 字幕。
- 支持用户导入 SRT/VTT。
- 不能绕过 DRM。
- 跨域 iframe 仍可能受站点权限和浏览器隔离限制，无法自动注入。
- 网站使用 Canvas、专用私有播放器或仅把字幕画进视频时，可能无法读取文字。
- 还没有内置语音识别。视频没有可读字幕时，需要先使用用户有权处理的 SRT/VTT，或后续接入 ASR。
- 全屏播放器如果是浏览器直接全屏 `<video>`，网页级扩展层可能无法显示；常见播放器使用容器全屏，可正常显示。

## 视频在播放但识别不到

先打开 Cue 的“设置”页，点击“诊断识别问题”，再点“复制结果”。通常属于以下情况：

1. **没有找到网页视频**：页面中存在 `iframe`，视频在跨域播放器里；当前注入脚本只能访问顶层页面。
2. **找到了视频但没有字幕**：原网站 CC 没有开启，或字幕由 Canvas/私有 API 渲染，而不是 HTML 字幕。
3. **有 TextTrack 但 cues 为 0**：字幕轨道受跨域限制，或播放器还没有加载对应语言。
4. **页面视频是隐藏元素**：平台可能把真实 `<video>` 隐藏起来，再由 Canvas 显示画面；需要站点适配。
5. **检测到 DRM mediaKeys**：受 DRM 保护的媒体不能直接读取字幕或音轨。
6. **网站更新过**：字幕 DOM 类名或接口发生变化，已有选择器可能失效。

网页更新后，需要点击 `chrome://extensions` 中 Cue 卡片的“重新加载”，并刷新视频网页。

## 文件结构

```text
manifest.json       Chrome/Edge 扩展配置
background.js       受限的跨域查词代理与帮助页
content.js          视频发现、字幕解析、时间同步、学习层和词库
page-bridge.js      页面主世界桥接，用于读取爱奇艺播放器字幕数据
HELP.html           扩展内使用说明
icons/              扩展图标
```

## 安全与隐私

- 没有设置常驻 `content_scripts`，也不会在所有网站自动运行。
- `activeTab` 只在用户点击扩展后临时授权当前页面。
- 字幕、收藏与偏好保存在浏览器的 `chrome.storage.local`。
- 只有用户点击“联网查词”或“翻译本句”时，相关短语/句子才会发送到第三方服务。
- 没有把任何 API Key 放进扩展代码。
